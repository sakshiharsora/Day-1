# Task 1 – Responsive Multi-Page Landing Website

## 📌 Project Overview
This project is a responsive multi-page business website created using pure HTML and CSS.  
It demonstrates modern UI/UX design, structured layout, responsive design, and clean styling without using any frameworks like Bootstrap.

The website includes multiple pages with a professional light theme, hover animations, and properly structured content.

## 🎯 Objective
To design and develop a clean, responsive landing website that includes:
- Header with navigation
- Hero section with background image
- Multiple content sections
- Footer
- Responsive layout using Flexbox
- Professional UI/UX styling

## 🛠 Technologies Used
- HTML5
- CSS3
- Flexbox
- Google Fonts (Poppins & Inter)
- Responsive Design (Media Queries)
